# 豆芽（Douya）隐私政策

最后更新日期：2026 年 8 月 22 日

## 概述

**豆芽**是一款运行在您电脑本地的 AI 聊天助手。本隐私政策说明豆芽如何处理您的数据。

**一句话总结：豆芽不收集、不上传、不出售任何个人信息。您所有数据只保存在您自己的电脑上。**

## 我们收集的数据

**我们没有收集任何数据。**

豆芽没有任何遥测、统计、广告、账号体系或云同步功能。我们不会收集您的姓名、邮箱、位置、设备信息或使用行为。

## 数据存储位置

豆芽产生的所有数据均保存在您的电脑本地：

- **聊天记录、设置、数据库**：存储在 `%LOCALAPPDATA%\Douya` 目录（Microsoft Store 版）或程序所在目录（官网便携版）。
- **AI 模型文件**：您手动下载的模型（GGUF 文件）存储在本地 `models` 目录。
- **推理后端**：您在首次使用时按需下载的本地推理引擎也存储在本地目录。

删除豆芽并清理上述目录后，您的数据即从电脑上完全移除，我们没有任何云端副本。

## 数据处理

- 您的对话内容仅在您电脑本地由本机运行的 AI 模型处理，**绝不会发送到我们的服务器**。
- 豆芽的网络请求仅发生在以下情形，且均由您主动触发：
  - 从 Microsoft Store 获取应用更新（商店版自动更新，由微软官方负责）；
  - 从 GitHub / ModelScope / Hugging Face 镜像站下载模型文件或推理后端组件；
  - 点击"查看 GitHub 仓库"等按钮跳转外部链接（跳转会离开豆芽，请查阅对应网站隐私政策）。
- 若您开启联网搜索功能，搜索请求会发往您配置的搜索服务提供方，其隐私实践由对应服务商负责。

## 第三方链接

豆芽"关于"页面包含外部链接（如 GitHub 仓库、交流群）。点击后将跳转至第三方网站，豆芽不对其隐私实践负责，建议您查看各网站隐私政策。

## 未成年人

豆芽不面向未成年人销售或定向投放，也无意收集未成年人信息。

## 政策变更

若本政策发生变更，我们会在应用内及本页面更新，并更新"最后更新日期"。
