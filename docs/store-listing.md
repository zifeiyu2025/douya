## 3. 详细描述（Description，商店页面正文）

**豆芽 - 本地AI 助手**

豆芽是一款**完全离线运行**的本地大模型（LLM）聊天助手。不需要联网、不需要注册账号、
不需要上传任何数据——你的所有对话都留在你自己的电脑里。

### 核心特点

- **100% 本地运行**：模型在你自己的电脑上推理，断网也能用
- **隐私优先**：对话记录加密存储在本地，绝不上传服务器
- **主流模型支持**：GGUF 格式模型即放即用（Qwen、Llama、Gemma 等）
- **硬件加速**：自动识别 NVIDIA GPU（CUDA）/ AMD · Intel（Vulkan），无 GPU 时自动使用 CPU
- **知识库问答（RAG）**：把文档喂给豆芽，直接基于自己的资料提问
- **多模态**：支持图文对话（llava 多模态模型）
- **会话管理**：多会话、上下文自动压缩管理长对话
- **联网搜索**（可选）：需要时可自行配置搜索引擎 API Key

### 使用说明

1. 安装后首次启动会自动下载/部署推理引擎（约 100~500MB，视硬件而定）
2. 将 `.gguf` 格式模型文件放入模型目录
3. 顶部选择模型，开始对话

> 提示：本应用为本地工具，模型文件较大（通常 1~10GB），请预留足够磁盘空间。
