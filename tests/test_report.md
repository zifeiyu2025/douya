## 已知问题与限制

### 1. "只思考不输出"问题（影响 2 个模型）
- **受影响模型**: Qwen3.5-9B-DeepSeek-V4-Flash、Qwen3.5-9B-Claude-4.6-Opus
- **现象**: 模型返回了 reasoning_content 但 content 为空
- **原因**: 部分蒸馏模型在简单对话时倾向于只输出思考内容，不输出正文
- **项目已有处理**: `thinking_content > 5x main_content` 时触发回退机制

### 2. Gemma-4-12b-it 加载失败（影响 1 个模型）
- **现象**: mmproj 加载失败（unknown projector type: gemma4uv），导致 llama-server 崩溃
- **原因**: 当前引擎版本不支持 gemma4uv 投影器类型
- **影响**: 该模型无法使用视觉功能，文本推理也因服务器崩溃而不可用
- **建议**: 等待引擎更新支持 gemma4uv，或在配置中为该模型禁用 mmproj

### 3. MTP 能力检测（影响 1 个模型）
- **受影响模型**: Qwen3.6-35B-A3B-UD
- **现象**: /props API 不报告 MTP 能力
- **说明**: MTP 能力通过项目内部的 GGUF 元数据解析检测（`nextn_predict_layers` 字段），不在 /props 返回中。项目内部逻辑正确识别了 MTP 能力。

### 4. Gemma-4-E4B-U 推理能力检测
- **现象**: /props 报告 reasoning=False，但实际推理测试通过
- **原因**: 该模型的 GGUF 元数据中可能缺少 `supports_preserve_reasoning` 标记，但实际支持推理

### 5. UI 测试架构限制
- **现象**: 通过浏览器直接访问 Vite dev server 无法进行交互测试
- **原因**: Wails 运行时绑定仅在桌面窗口中可用
- **建议**: 使用 Chrome DevTools Protocol 连接 Wails webview2 进行完整 UI 测试
